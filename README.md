ZBW_BMS-

本项目基于 STM32F103C8T6 与 TI BQ7692003PWR 的四串锂电池管理系统，面向锂电池电压采集、电流检测、温度监测及充放电保护等应用场景。

项目介绍

本项目是基于德州仪器BQ7692003PWR与STM32组成的四节锂电池管理系统 附加功能包括CAN通信和蓝牙通信。目前已完成原理图设计与 PCB 设计，后续将继续进行底层驱动开发、系统联调及保护功能验证。

主要硬件采用

| 主控 MCU        STM32F103C8T6 
| 电池监测 AFE    TI BQ7692003 
| 电池组配置      4S 锂离子电池 （单节3.7v）
| 电流采样        5mΩ 采样电阻 
| 充放电控制      MOSFET 功率开关电路 
| 电源管理        MP1584 降压电路 
| CAN 通信        SN65HVD230 
| 蓝牙通信        JDY-23 模块 
| 硬件设计工具    嘉立创EDA（专业版） 

设计功能

计划实现以下功能：

- 电芯电压采集：采集四串电池各节电芯的电压信息。
- 电池组电流检测： 通过采样电阻获取充放电电流信息。
- 温度监测： 通过 NTC 热敏电阻检测温度。
- 电池保护： 根据电压、电流及温度状态实现相应的保护控制。
- 充放电管理： 配合 MOSFET 功率开关实现充放电通路控制。
- *通信接口： 预留蓝牙与 CAN 通信功能，用于后续状态上报和数据交互。

> 以上为设计目标，具体功能以实际硬件调试和软件验证结果为准。

 硬件设计

 1. 电池监测电路

使用 BQ7692003 作为电池模拟前端（AFE），负责电芯电压监测及相关保护检测。主控 MCU 后续通过 I²C 接口完成寄存器配置、状态读取和数据处理。

 2. 主控电路

使用 STM32F103C8T6 作为系统控制核心，计划完成 AFE 驱动、数据采集、保护逻辑及通信协议等软件模块。

 3. 功率控制电路

采用 MOSFET 功率开关与采样电阻构成主电流通路，实现充放电控制及电流检测。实际电流能力需结合 MOSFET 导通损耗、PCB 铜箔、连接器和热设计进行验证。

 4. 电源与通信电路

使用 MP1584 构建降压电源电路，并设计 CAN 与蓝牙通信接口，为后续系统调试、状态监控和数据传输提供硬件基础。
